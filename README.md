# Rust Playground — learn one lesson at a time

Requires Rust and Cargo: https://rustup.rs/

Open a terminal in this folder and run:

```bash
cargo run --bin 01_variables
```

Each lesson is a separate executable in `src/bin/`. Edit a file, rerun its command, and experiment with the `TRY` comment.

## Lessons

- `01_variables.rs` → `cargo run --bin 01_variables`
- `02_data_types.rs` → `cargo run --bin 02_data_types`
- `03_if_else.rs` → `cargo run --bin 03_if_else`
- `04_loops.rs` → `cargo run --bin 04_loops`
- `05_functions.rs` → `cargo run --bin 05_functions`
- `06_ownership.rs` → `cargo run --bin 06_ownership`
- `07_struct.rs` → `cargo run --bin 07_struct`
- `08_enum_match.rs` → `cargo run --bin 08_enum_match`
- `09_vector.rs` → `cargo run --bin 09_vector`
- `10_option_result.rs` → `cargo run --bin 10_option_result`
- `11_hashmap.rs` → `cargo run --bin 11_hashmap`
- `12_traits_generics.rs` → `cargo run --bin 12_traits_generics`

## Useful commands

- `cargo run` — welcome message
- `cargo check --bins` — type-check all lessons
- `cargo build --bins` — compile all lessons
- `cargo fmt` — format Rust source files

No external dependencies required. Compatible with Windows, macOS, and Linux.
